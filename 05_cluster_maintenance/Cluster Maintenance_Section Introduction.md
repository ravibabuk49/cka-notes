## Cluster Maintenance: Section Introduction

### What it is

This domain covers the operational lifecycle of a Kubernetes cluster — from safely removing nodes for OS patching, through controlled cluster version upgrades, to backup and disaster recovery of cluster state.

---

### Topics Covered in This Domain

| Section | Topic |
|---|---|
| 01 | OS Upgrades — node drain, cordon, eviction implications |
| 02 | Kubernetes Releases and Versioning |
| 03 | Cluster Upgrade Process (kubeadm) |
| 04 | Backup and Restore Methodologies |

---

### Exam Weight

Cluster Maintenance is a scored domain in the CKA exam. Expect hands-on tasks around:
- Draining and uncordoning nodes
- Upgrading a cluster using `kubeadm`
- Taking and restoring an etcd snapshot
